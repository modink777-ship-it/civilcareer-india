# CivilCareer — Phases 6 + 14 + 15 + 16

This release combines:
- Phase 6: Job Portal Core Upgrade
- Phase 14: Analytics & Admin Intelligence
- Phase 15: Automation & Job Discovery safety
- Phase 16: Performance, Mobile & PWA

## Free-only
No paid service, paid API, subscription, or new billing requirement was added.

## Main changes
- Added `portal-v16.js` for advanced portal filtering/sorting, government experience/salary filters, admin inventory insights, discovery-health indicators, and mobile/offline UX.
- Added `portal-v16.css` for responsive portal/admin components.
- Strengthened `api/jobs.js`:
  - public detail lookup by `id`/`slug`
  - public-field projection
  - private application email protection
  - duplicate warning/block for obvious same role + employer + location imports
- Strengthened `api/analytics.js` with a direct aggregation fallback if the existing analytics RPC is unavailable.
- Strengthened `scripts/scrape-jobs.js` duplicate detection while keeping all imported jobs as drafts.
- Updated the service worker to v16 with network-first behavior for live HTML/API data so old job pages are not preferentially served after deployment.

## Deployment
1. Replace the contents of your GitHub repository with the contents of this ZIP's `civilcareer-india-main` folder (select all files/folders inside it, not the outer folder).
2. Commit and push.
3. Wait for Vercel to show the deployment as Ready.
4. Hard refresh the website once after deployment.

No Supabase migration is required for this release.

## Important
The existing Gemini/Telegram scraper secrets remain optional. Nothing new requires a paid API.
