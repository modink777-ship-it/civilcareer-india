# CivilCareer Blueprint Navy and Brass design system

The existing CSS remains the primary design surface. New work should use the established navy/brass palette and semantic status colours rather than ad-hoc colours. Public pages must remain English-only, mobile-first, and support reduced motion and light/dark themes where the existing theme system provides them.

Current verification in this run: no duplicate form IDs were found within static forms; the late CSS `@import` was removed and fonts are loaded with `<link>` tags.
