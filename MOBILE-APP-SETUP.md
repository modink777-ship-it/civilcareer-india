# CivilCareer Mobile App

The site is now a mobile-friendly Progressive Web App (PWA).

## Install prompt
The website shows an **Install CivilCareer** prompt on supported browsers. Android/Chrome can use the native install prompt. iPhone/iPad users receive the Safari Add to Home Screen instructions.

## Public zero-cost link
Deploy this folder to Vercel or Cloudflare Pages on their free tiers. They provide an HTTPS URL that you can share with everyone.

## Google Play
A PWA can be packaged for Google Play using a Trusted Web Activity with Bubblewrap or PWABuilder. Google Play distribution is not completely free: Google Play Console currently has a one-time registration fee (check Google's current pricing/terms). The PWA itself remains free to users.

## API
No special download API is required for PWA installation. Existing job/live-stat APIs can continue to run normally.
