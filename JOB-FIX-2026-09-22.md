- Discovery results now hide jobs already present on CivilCareer.
- Manual job creation checks duplicates and reports `Already exists`.
- Successful new posts report `Job added successfully.`
- Job detail pages no longer receive the generic photo background layer.
- Job detail hard refresh is more resilient and displays singular fallback fields.
- Homepage `How CivilCareer works` is moved below `Latest opportunities`.
- Extraction API uses Groq -> Gemini Flash-Lite -> Gemini Flash failover.
- Profile modal cancel/close now uses the real overlay close function.
- No new Vercel API function was added.
