# Job Listing Layout Fix

- Job cards are intentionally compact: status, posted time, company, role, location, experience, up to three tags, and actions.
- Long job descriptions are shown only in the selected-job detail pane.
- Private and government listings use a horizontal filter bar.
- Private geographic scope (All India / State-wise / City-wise / International) is part of that horizontal bar.
- Job results remain in the main left column; selected-job details appear in the right pane on desktop and below the cards on smaller screens.
- Existing For You personalization, mobile header, search, and live stats changes are retained.
